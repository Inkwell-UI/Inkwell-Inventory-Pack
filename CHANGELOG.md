# Changelog

## 0.1.2

Supports any Inkwell from 0.5.0 on (compatible.tool is now >=0.5.0 instead of ^0.x). No node, pin, field or template changed.

## 0.1.1

Every node now has an Inspector description. No pin, field or template changed.

## 0.1.0

First release: the 15 inventory contract nodes of the Core Pack, all `inventory/<Kind>@1` (contract `InventoryMenu`, category Inventory). Pins, fields and templates are the Core Pack's; only the id differs.

- Events: On Key, On Attempt Equip, On Drop Item, On Invalidate List, On Item Card, On Player Info, On Restore Indices, On Set Categories.
- Actions: Close Menu, Item Drop, Item Select, Play Sound, Request Item Card, Save Indices, Update Item 3D.
